# Writing style

Write all English output in ASD-STE100 Simplified Technical English (STE).
This includes replies, code comments, commit messages, pull request descriptions and documentation.
It does not include code identifiers, quoted text, command output or text that you do not change.

- Use approved STE words with their approved meaning. Use one word for one meaning.
- Use technical names and technical verbs from the project when no approved word is applicable.
- Keep procedural sentences to 20 words or fewer, and descriptive sentences to 25 words or fewer.
- Write one instruction in each sentence. Use the imperative for instructions.
- Use the active voice. Use only the simple present, simple past and simple future tenses.
- Do not use the -ing form of a verb, except in technical names.
- Use articles ("a", "an", "the") and "this" or "these" where possible.
- Do not make noun clusters of more than three words.
- Keep paragraphs to six sentences or fewer, with one topic in each paragraph.
- Use a list for a sequence of steps or for parallel items.
- Write warnings and cautions as a short command, then give the reason.
